# ZERO01E Docs Index

이 디렉터리는 현재 코드 기준 문서를 `전역 개요 + 개별 상세` 구조로 관리합니다.

## 문서 맵

- `PROJECT_STRUCTURE.md`
  - 프로젝트 전체 구조, 라우트, 주요 컴포넌트/상수 배치
- `DEVELOPMENT_STATUS.md`
  - 현재까지 구현 완료/진행/예정 항목과 리스크
- `DIAGNOSIS_SYSTEM.md`
  - 블로그 수익화 진단 기능(퀴즈/리드폼/API/결과) 상세 명세
- `CODEX_GUIDE.md`
  - Codex 작업 기준(문서 우선순위, 수정 규칙, 체크리스트)

## 문서 운영 원칙

- 기준 소스: 코드 우선 (`app`, `components`, `constants`)
- 문서 갱신 시점: 기능 추가/삭제, 라우트 변경, API 스펙 변경 시
- 상태 기준일 표기: 문서 상단 또는 본문에 `기준일` 명시
